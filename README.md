# VGSales Analyzer 🎮

🇧🇷 Ferramenta via terminal para análise de dados de vendas de jogos eletrônicos usando o dataset VGSales.

🇺🇸 Command-line tool for analyzing video game sales data using the VGSales dataset.

---

## Funcionalidades / Features

- 🇧🇷 Top N jogos mais vendidos — globalmente, por ano ou por gênero
- 🇧🇷 Busca de informações por nome do jogo
- 🇺🇸 Top N best-selling games — globally, by year or by genre
- 🇺🇸 Search game information by name

---

## Versões / Versions

- `app.py` — versão atual usando banco de dados SQLite
- `app_v1.py` — versão original usando arquivo CSV

---
